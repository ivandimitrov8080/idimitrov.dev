## OTC IRS Products & Currencies

### [Release notes](https://www.eurex.com/ec-en/support/initiatives/c7-client-administration-service/C7-CAS-Releases-2900566?frag=4120024)

This release extends C7 CAS by adding the ability to request activation/deactivation of supported OTC IRS
products and currencies in a member's configuration, replacing prior paper-based administration.

## Reporting ID redesign

### [Release notes](https://www.eurex.com/ec-en/support/initiatives/c7-client-administration-service/C7-CAS-Releases-2900566?frag=4722664)

This release redesigns the Reporting ID functionality by introducing a new admission type **OTC Report Receiver**.
Members can request a new report receiver which can later be linked to DC position accounts.
